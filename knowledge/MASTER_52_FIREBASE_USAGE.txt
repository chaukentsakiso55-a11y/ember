52. FIREBASE USAGE
================================================================================

Firebase has been repeatedly used as the main backend direction.

Uses:
- authentication
- pairing
- syncing
- user accounts
- app data
- student/parent state
- teacher classes
- AI-related app support
- cloud data

Projects associated with Firebase:
- StudyLock
- GuardianAI
- Evolution Learning
- Study AI
- Star AI
- Cyber Pulse website

One of the major lessons in the project history:
the UI can appear correct while Firebase rules, app registration, package identity, auth, or schema still prevent the actual system from working.
